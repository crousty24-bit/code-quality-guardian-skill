# Support

## Usage Questions

Open a GitHub issue using the bug report form when:

- installation or discovery fails;
- the skill is not invoked as expected;
- a bundled script returns incorrect or unsafe output;
- documented commands do not match current CLI behavior.

Include the operating system, agent, Python version, `skills` CLI version, installation scope, command output, and the relevant repository type.

## Behavior Feedback

For classification or orchestration feedback, include:

- the prompt;
- expected and observed intervention level;
- specialist skills selected;
- files and lines changed;
- commands actually executed;
- false positives or unsupported claims;
- remaining uncertainty.

Do not include proprietary source code, secrets, credentials, or personal data.

## Security

Use [SECURITY.md](SECURITY.md) for vulnerabilities. Do not report exploitable security issues through a public support issue.
